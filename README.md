## Objetivo
El conjunto de datos de TMDB (The Movie Database) reúne información sobre películas de distintos géneros, años y países a nivel global, incluyendo atributos como género, fecha de estreno, presupuesto, calificaciones del público e ingresos generados. 

Este conjunto de datos permite explorar y analizar los factores relacionados con el desempeño comercial de las películas y, en particular, responder a la pregunta de investigación: ¿qué características de una película están asociadas con mayores ingresos de taquilla?. A partir de esta información, se busca identificar patrones y relaciones que ayuden a comprender qué factores se encuentran vinculados con un mejor desempeño en términos de recaudación.

El propósito de este trabajo es realizar un análisis exploratorio de datos, y posteriormente, desarrollar un modelo predictivo que permita identificar los principales factores asociados con los ingresos obtenidos por las películas registradas en la muestra de TMDB.
